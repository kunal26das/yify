The receipt retains six API36 and four API37 screenshot hashes. It did not exercise home, add/save, connected catalog or movie detail, account/sign-in, purchase/restore, ads, or external providers. The installed splits used a temporary test signer, so this gate does not prove Play-delivered APK signing or behavior on physical devices. The release lead reports final QA and an independent reviewer approved the exact candidate within this bounded offline scope, including rollback readiness, before Play submission. [Exact-source CI 39253896513](https://github.com/kunal26das/yify/actions/runs/39253896513) passed; the fixed GitHub verifier workflow remains historical code 105 and was not run for code 108.
